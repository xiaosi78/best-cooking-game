Rush Hour Kitchen is a fast 2D canvas cooking game: run the lunch rush, chop and cook each order's ingredients, build the dish on the assembly counter, and serve it at the window before the timer — or the patience — runs out.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
